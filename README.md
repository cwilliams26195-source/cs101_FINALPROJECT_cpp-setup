Sports Team Registration System:

-A multi-file C++ console program for registering students into school sports teams: Basketball, Football, Volleyball, Softball, and Track and Field.

Project Files:
 Student.h & Student.cpp — Student class with private fields (name, id, age, sport) and print() method.
 Registration.h & Registration.cpp — Registration class with a std::array of 5 sports, a std::vector of students, duplicate ID checks, search, and sport summary.
 main.cpp — Menu loop (do-while and switch) and input checks.
-docs — Project proposal and technical report files.
